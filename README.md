# Resume AI Bot

An AI-powered assistant designed to showcase resume details, experience, skills, and answer interactive questions about my portfolio.

## 🚀 Features (Planned)
- **Interactive Q&A**: Ask questions about my professional experience, projects, and skills.
- **AI-Powered Summary**: Key highlights tailored to dynamic visitor queries.
- **Portfolio Showcase**: Interactive presentation of project case studies.

## 🛠️ Built With
- Modern Web Framework / JavaScript
- AI / LLM APIs
